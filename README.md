# ドージョーボード

CoderDojoでイベントごとのふきだしを共有するWebアプリです。サーバーで投稿を保存し、参加者のブラウザに共有します。ローカルNode.js版、Sites版、ColorfulBox向けPHP版があります。

## 公開アプリ

**[ドージョーボードを開く](https://fukidashi-nanoz.nakauchi-s.chatgpt.site/admin)**

1. 管理者が上のリンクからイベント名と表示名を入力し、「作成する」を押します。
2. 「公開URLを生成」を押すと、参加用のQRコードが表示されます。
3. 親御さんやニンジャはスマホでQRコードを読み取り、表示名とふきだしを入力して投稿します。
4. 会場のボードは約1.2秒ごとに自動更新されます。Macの起動や同じWi-Fiへの接続、参加者のGitHubログインは不要です。

管理者の操作権限は、イベントを作成したブラウザに保存されます。同じブラウザから開き直してください。以前のMac内の投稿はクラウド版へ自動移行されません。

GitHub Pagesの入口（`docs/`）からも公開アプリへ移動できます。リポジトリのコード画面には投稿は表示されません。

クラウド版はSitesのCloudflare WorkerとD1で動作し、投稿は再配置後も保持されます。公開アプリのURLやQRを知っている人が閲覧・参加できます。ローカルNode.js版とは保存先が別です。クラウドの実装と検証手順は[cloud/README.md](cloud/README.md)を参照してください。

## インターネットから使うには

### 那須野崎のColorfulBoxで運用する準備

PHP 8.4・専用MariaDBに対応した実装と、非公開の設定・バックアップ構成を用意しています。**配置・検証の手順は[php/README.md](php/README.md)**を参照してください。画面は現在のままです。以下で接続情報を含まない配布ファイルを作成できます。

```sh
npm run package:colorfulbox
```

これは移行用コードの準備です。現在の公開先、DNS、案内リンクは自動変更しません。

### Node.jsで運用する場合

GitHubはソースコードの管理先です。このアプリには投稿を保存・共有するサーバーが必要なため、GitHub Pagesだけでは動作しません。

Node.js 20以上が動作する公開サーバーにこのリポジトリを配置し、`npm ci`、`npm start`で起動します。待ち受けポートは環境変数`PORT`で指定できます（既定値: 4177）。HTTPSでアクセスできるURLを設定してください。

管理者は公開サーバーの`/admin`を開き、イベントを作成して「公開URLを生成」を押します。参加者は表示されたURLまたはQRコードから参加できます。各自がインターネットに接続できれば、同じWi-Fiに接続する必要はありません。

投稿は`data/boards.json`に保存されます。このディレクトリは公開せず、再起動や再デプロイでも失われない永続ストレージに置いてください。複数のNode.jsプロセスで同じファイルを共有する構成には対応していません。投稿データはGitHubへのアップロード対象外です。

以下は、自分のMacを会場内のサーバーとして使う場合の手順です。

## 事前準備

MBPにNode.js 20以上を入れて、このリポジトリをcloneします。

```sh
git clone https://github.com/nasunozaki-prokura/fukidashi-nanoz.git
cd fukidashi-nanoz
npm ci
```

## 当日の起動

ホームルーターを起動し、MBPをそのWi-Fiに接続してから起動します。

```sh
npm start
```

起動すると、ターミナルに次のようなURLが表示されます。

```text
LAN admin URLs:
  http://192.168.0.4:4177/admin
```

MBPのブラウザで表示された `/admin` のURLを開き、イベントを作成して「公開URLを生成」を押します。画面左側に参加用QRコードが出ます。

## 参加者

同じWi-Fiに接続しているスマホ、タブレット、PCからQRコードを読み取ると、ふきだしを書き込めます。書き込みは管理者画面に自動更新で表示されます。

## 会場で確認すること

- MBPと参加者端末が同じWi-Fiに接続されている
- macOSのファイアウォールでNode.jsの受信が許可されている
- ルーターの端末間通信制限、AP isolation、プライバシーセパレーターが無効になっている
- MBPがスリープしない設定になっている

## URLを固定したい場合

MBPのIPアドレスが変わるとQRコードのURLも変わります。必要なら、ホームルーター側でMBPに固定IPを割り当ててください。
